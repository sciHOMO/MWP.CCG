# 红色 · 践踏溢出系 · R-001 ~ R-010

**状态：已定稿。**

## 体系论点

伤害不该停在尸体上。红色是那簇在被域外存在封装进土石**之前**的火——
"摧毁一切物理层面的功能结构"——外壳约束不住它，所以超量部分必须漏出去。

这个体系的核心命题是：**解场和斩杀是同一个动作。**

| | |
|---|---|

| 类型 | 生物 · 异兽 |

| 属性 | 践踏 |

体系的第一课。3 攻撞掉一个 1/1，2 点漏到指挥官身上——它在第一回合就在演示

### R-002 淬火砧

| | |
|---|---|
| 等级 | LV0 |
| 类型 | 武装 |
| 耐久 | 2 |

装备生物获得 +2/+0 与践踏。

### R-005 穿膛烈焰

| | |
|---|---|
| 等级 | LV1 |
| 类型 | 法术 · 战技 |

对目标生物造成 4 点伤害。**此伤害具有践踏。**
**余响（仅可从回响区支付）**：你本回合施放的法术具有践踏。

法术自带践踏是这套设计最锋利的一点：一张解场牌同时是斩杀牌。

余响不是一次小伤害，而是**把整个回合的法术全部变成溢出源**。
锁定从回响区支付，所以它必须先被用掉一次才能开这个模式——
一段已经烧过的记忆，第二次读取时反而打开了更深的东西。

这条法术路线**绕过守护墙**，是红色对抗铺场防御的答案。

> 火不在乎前面站着几个人。

### R-006 焚巷

| | |
|---|---|
| 等级 | LV1 |
| 类型 | 地形 |
| 耐久 | 3 |

你的生物的践踏伤害溢出到对手的指挥官时，对对手的一个生物造成 1 点伤害。

**确立了「溢出触发」这一整个触发族。** 它把践踏从纯斩杀手段改造成同时控场的手段：
你每打穿一次，对手的战线就再薄一层，而战线越薄，你下一次的溢出就越大。
这是体系的核心正反馈，也是红色中期不至于后继无力的原因。

做成地形而非生物有两个理由：体系原本生物过多；挂在 3/3 身上的触发器太容易被
顺手解掉，而地形要求对手专门带拆地形的牌。而它本来就该是一个地方——
帝国的城区绥靖区，烧过一遍的巷子。

> 那天有卖糖的。

### R-007 碾骨统帅

| | |
|---|---|
| 等级 | LV2 |
| 类型 | 生物 · 人类 · 统帅 |
| 数值 | 5/4 |
| 苛求 | 〈2 张红〉 |

你的具有践踏的生物获得 +1/+0。
你的生物的践踏伤害溢出到对手的指挥官时，抽一张牌。

体系的过牌轴。红色不该有通用抽牌——它应该靠**正确地打出伤害**来换资源。
每回合溢出一次就是一张牌，这让倾泻手牌的打法能自己续上。

+1/+0 只吃践踏生物，所以它不会让体系外的大生物失控。

| | |
|---|---|

## 内部分工

| 角色 | 卡牌 |
|---|---|
| 载体（自带践踏） | R-001、R-003、R-009、R-010 |
| 赋予器（把践踏给出去） | R-002、R-004 |
| 放大器（把溢出做大） | R-008、R-007 的 +1/+0 |
| 溢出触发（把溢出换成资源） | R-006（控场）、R-007（过牌） |
| 解场兼斩杀 | R-005 |

牌型分布：5 生物 / 3 法术 / 1 武装 / 1 地形。

十张里没有任何防御牌，这是有意的：**践踏体系不防守，
它只能靠逼迫对手来换取生存空间。** 防御工具留给红色的另外三十张。

## 斩杀线核算

**R-010 + R-008**：7/5 双倍践踏获得 +4/+4，变为 11/9。撞对手一个 3/3：
3 点杀掉它，8 点超量，**双倍后 16 点直击指挥官**。而它有 9 点血，打完还站着。

**R-010 + R-008 + R-004**：14/12。同样撞 3/3：11 点超量，**双倍 22 点**——
25 血只剩 3 点。总投入 LV3 + LV2 + LV1 = 9 张牌，是一条合理的后期斩杀。

**法术路线**（R-005 从回响区开启）：本回合所有法术具践踏，
穿膛烈焰打 4 杀掉一个 2/2 就漏 2 点，两三张直伤叠起来能在完全不依赖生物的
情况下收掉残血对手。

**接上将军（R-038，玩家设计，机制不动）**：将军攻击 → 全场 +1/+1 →
其他生物消灭对手生物 → 恢复未行动 → 带着 R-002 / R-004 给的践踏再打一轮。
