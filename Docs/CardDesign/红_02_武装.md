# 红色 · 武装系 · R-011 ~ R-020

**状态：已定稿。**

## 体系论点

武具比持有者活得久。一件器物被反复捡起、反复使用、反复丢下，
而每一次捡起它的手都更强一点。

引擎闭环：**一次性武装打出 → 给一次 buff → 回合结束时自己掉 → 沉入回响区 → 下回合被捞回来再打一次。**

回响区在这个体系里不是墓地，是**工具架**。

## 关键节流：耐久 1 自减

一次性武装（R-011、R-012）为 `耐久 1`，且 **你的回合结束时耐久 -1**。

这条设计把引擎钉死成 **每件武装每回合只能触发一次**。
若改为"装备时立即移入回响区"，则捞子（R-013、R-016）会变成乘数，
同一回合反复捞回同一件武装重复触发，成长会失控。

涌现细节：**对手拆掉已经触发过的一次性武装，等于帮它提前进回响区。**
拆武装类的牌在这个体系面前会犯错。

|---|---|

| 类型 | 武装 |

装备时：装备生物获得 +2/+2，直到回合结束。

| | |
|---|---|
| 等级 | LV0 |
| 类型 | 武装 |
| 耐久 | 1 |

装备时：对目标生物造成 2 点伤害。

### R-015 拆解爆能

| | |
|---|---|
| 等级 | LV1 |
| 类型 | 法术 · 炼成 |
| 苛求 | 〈1 张武装〉 |

对目标生物造成 5 点伤害。
**余响**：对目标生物造成 2 点伤害。

拆一件器物换一发更大的伤害。5 点超出 LV1 档位（穿膛烈焰是 4 点），
超出的部分就是那件武装的价钱。

这里第一次把苛求用在牌型而非颜色上。`苛求〈1 张武装〉` 的门槛远紧于
`苛求〈1 张色〉`，是有效门槛，值得返还价值。

### R-016 重铸令

| | |
|---|---|
| 等级 | LV1 |
| 类型 | 法术 · 炼成 |

将你的回响区的最多两张武装牌放入你的手牌。
**余响**：将你的回响区的一张武装牌放入你的手牌。

体系的续航。一张换两件，而且它自己被支付掉之后还能再换回一件。

这里有一个真实的取舍：捞回来的武装可以下回合再装一次触发成长，
也可以留着喂 R-020。**你不能两样都要。**

### R-018 灵能过载钳

| | |
|---|---|
| 等级 | LV2 |
| 类型 | 武装 |
| 耐久 | 2 |
| 苛求 | 〈2 张红〉 |

装备生物获得 **+2/+2**。
装备生物攻击一个生物时，**对与该生物相邻的生物各造成等同于此生物攻击力的伤害**。
装备生物攻击时，此武装的耐久 -1。

只做一件事：把每一次攻击变成一次横扫。

与体系天然咬合——熔铸圣徒长到 10 攻之后，这把钳子的每一挥都是对相邻两格
各 10 点。两次耐久是一个**窗口**，不是一台引擎。

**践踏是纵向溢出**（穿过身体打到指挥官），**横扫是横向溢出**（漏到邻居身上）。
同一个红色论点的两个轴，机制上互不重叠，装在同一具身体上就是纵横都漏。

相邻的定义按 **同排左右相邻的两格**。代码侧 `ACardModel` 已有 `FIntPoint Position`。

> 钳口合上的时候，整条街的灵能管道一起响了一声。

### R-019 全境拆解

| | |
|---|---|
| 等级 | LV2 |
| 类型 | 法术 · 炼成 |
| 苛求 | 〈2 张武装〉 |

对对手的所有生物造成 3 点伤害。对对手的指挥官造成 2 点伤害。

**红色的防御手段，且完全长在体系上。** 拆两件器物换一次清场——
对兽潮、铺场、衍生物体系是毁灭性的，顺带 2 点让它在斩杀回合也不是废牌。

设定上这是炼金师把整条街的器物拆了当弹药。帝国自己就是这么干的：
宗教审判把民众收集来的灵能器物连同罪犯一起焚化。

### R-020 十八人的终锻

| | |
|---|---|
| 等级 | LV4 |
| 类型 | 传说武装 |
| 耐久 | 3（不自减） |
| 苛求 | 〈3 张武装〉 |

装备生物获得 **+X/+2**，X 为你以此法支付的武装牌的**等级之和**。
登场：宣言一个生物，将其放逐。

玩家设计。三点说明：

**X 的现实区间**：由于回响区的卡牌可以被支付为代价，而一次性武装会不断
沉积在那里，到第 8 回合前后回响区通常躺着 5 ~ 8 件武装，可以挑最贵的三件喂。
喂三件 LV2 是 +6/+2，喂到 LV3 是 +9/+2。

**反直觉的构筑张力**：高等级武装打出来很亏，但喂进去很赚。
所以牌组会故意带几件"本来不打算用"的贵武装当燃料。

**"率先放逐"的实际意义**：放逐在装备之前结算，所以可以**先抹掉守护墙，
再装上这把锤子，同一回合挥出去**。放逐不是伤害，守护挡不住，护盾防不了。
这是红色唯一的永久放逐手段。

> 它在被举起之前就已经念出了名字。
>
> 十八个人锻的最后一件东西。他们锻完它，然后烧掉了所有还会锻造的人。

## 内部分工

| 角色 | 卡牌 |
|---|---|
| 一次性武装（引擎燃料） | R-011、R-012 |
| 横扫武装（持续，2 次窗口） | R-018 |
| 装备即成长（引擎输出） | R-014、R-017 |
| 消耗武具（转伤害） | R-015、R-019 |
| 回响区捞子（引擎续航） | R-013、R-016 |
| 终结 | R-020 |

牌型分布：**4 武装 / 3 生物 / 3 法术**——足够密的武装数量让
`苛求〈3 张武装〉` 与 `苛求〈2 张武装〉` 真的能支付。

## 典型引擎回合

场上有 R-017（4/5）。手里三张 R-011（LV0，免费）。全部装上：
R-017 变 **10/11**，同时打出 6 点分散伤害清掉对手三个小兵，
三件短锋在回合结束时全部掉进回响区。下回合 R-016 捞回两件再来一遍。

## 与践踏系的接口

红色因此有两条独立赢法：践踏溢出靠穿透，武装靠单点做大加放逐开路。
两者共享 R-002 / R-004 的践踏赋予——**一把 +9/+2 的锤子加上践踏，
是这个游戏里最大的一次单点溢出。**
