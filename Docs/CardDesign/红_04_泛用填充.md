# 红色 · 泛用填充 · R-031 ~ R-040

**状态：已定稿（数值可能微调）。**

## 这一批要补的缺口

前 30 张（践踏溢出 / 武装 / 佣兵）跑完后的审计结果：

**通用 AOE 是真空。** 唯二的 AOE 是 R-019 全境拆解（锁在 `苛求〈2 张武装〉`）
与 R-018 灵能过载钳（只打相邻两格且需先装备）。整个红色没有一张
任何牌组都能带的清场牌——这对一个以火为核心意象的颜色说不过去，
而且意味着红色打不了铺场对局。

**牌型偏斜。** 前 30 张是 16 生物 / 7 法术 / 5 武装 / 2 地形，法术严重不足。
故这一批以法术为主。

## 卡表

### R-031 燃芯

| | |
|---|---|
| 等级 | LV0 |
| 类型 | 法术 · 战技 |

对目标生物造成 2 点伤害。
**余响**：对目标生物造成 1 点伤害。

最便宜的点杀。LV0 意味着打出它不需要牺牲任何东西，

### R-032 燃巢地脉

| | |
|---|---|
| 等级 | LV2 |
| 类型 | 地形 |
| 耐久 | 3 |
| 苛求 | 〈2 张红〉 |

你的回合开始时，对对手的**所有生物**造成 1 点伤害。
你的生物获得 +1/+0。

**AOE 最低档：持续性。** 单次只有 1 点，但每回合自动运转且难以移除——
对衍生物、兽潮、佣兵光环网络是慢性绝症。
+1/+0 让它在对空场时也不是白板。

### R-033 锈蚀溶剂

| | |
|---|---|
| 等级 | LV1 |
| 类型 | 法术 · 炼成 |

摧毁目标武装或地形。若你无法这么做，则对目标生物造成 3 点伤害。
**余响**：使目标武装或地形的耐久 -1。

### R-035 熔穿

| | |
|---|---|
| 等级 | LV2 |
| 类型 | 法术 · 战技 |

对目标生物造成 6 点伤害。若此伤害消灭了它，对其操控者的指挥官造成 2 点伤害。

通用大解场加延伸伤害。那 2 点是**有条件的**——只在真的杀掉目标时触发，
对手可以垫刀或用大血量生物规避。红色可以打脸，但不能防不胜防。

### R-036 灵能过载

| | |
|---|---|
| 等级 | LV2 |
| 类型 | 法术 · 炼成 |
| 苛求 | 〈2 张红〉 |

对**所有生物**造成 4 点伤害。**你的具有践踏的生物不受此伤害。**

**AOE 中档：主力清场，同时是红色的防御手段。** 对称，但豁免自己的践踏生物——
践踏牌组可以在濒死时按下它，清空对手战线而保留自己的溢出源，
下回合直接进斩杀。

不打践踏的红色牌组带它会连自己一起清掉。这个约束是故意的：
**红色不该有一张无脑的万能清场。**

### R-038 拓土将军

| | |
|---|---|
| 等级 | LV4 |
| 类型 | 传说生物 · 人类 · 统帅 |
| 数值 | 6/4 |
| 苛求 | 〈2 张红〉 |

本生物攻击时，你的其他生物获得 +1/+1。
你的其他生物消灭对手生物时，恢复未行动状态。

**玩家设计，机制一字未动。** 仅补三样卡面信息：种族职业、苛求、设定内名字。

苛求给 2 而不是 3，因为机制是定稿的，再加紧门槛等于变相削弱。
其总价值略高于 LV4 曲线，这是对的——终结手段就该让人感觉到
"打出来基本就赢了"。

设定上他是帝国拓张战争的将军。对帝国而言多余的人口只是累赘；
而对灵能平民而言为帝国而死能封妻荫子。**所以他的士兵杀得越多、死得越快，
队伍就越强——这不是隐喻，这就是他的效果文本。**

> 他的战功从不记录伤亡。伤亡是另一本账，由教会保管，不外传。

### R-039 焚城令

| | |
|---|---|
| 等级 | LV3 |
| 类型 | 法术 · 契文 |
| 苛求 | 〈2 张红〉 |

对**所有生物**造成 7 点伤害。对**所有指挥官**造成 3 点伤害。

**AOE 高档：全面重置。** 7 点几乎清掉场上一切，包括你自己的。

血线领先时你按得比对手舒服。

宗教审判的极端形态，也是灵能引擎彻底失控的样子。

> ◇ 净化程序已升级为区域级。请勿撤离，撤离即认罪。
