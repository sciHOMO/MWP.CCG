# 数值基准与通用纪律

本文件是全部卡牌设计的校准尺。任何一张牌的数值争议以此为准。

## 等级与代价

`LVn` 表示打出该牌需要牺牲 n 张卡牌作为代价。卡牌自身也计入投入，
因此一张 `LVn` 卡牌的总投入为 `n+1` 张牌。

## 总价值预算

```
总价值 = (LV + 1) × 4
```

以炉石传说为外部参照系：一张牌约等于 2 费，故 `LVn` 约等于 `(n+1) × 2` 费。

| 等级 | 总投入 | 等效费用 | 白板数值基准 |
|---|---|---|---|
| LV0 | 1 张 | 2 费 | 3/2 |
| LV1 | 2 张 | 4 费 | 4/4 |
| LV2 | 3 张 | 6 费 | 6/6 |
| LV3 | 4 张 | 8 费 | 8/8 |
| LV4 | 5 张 | 10 费 | 10/10 |

异能从总价值中扣减。参考价位：

| 异能 | 约值 |
|---|---|
| 守护 | 2 |
| 先击 | 2 |
| 践踏（低攻身体） | 1.5 ~ 2 |
| 践踏（高攻身体） | 3 |
| 潜行 | 3 |
| 护盾 | 3 |
| 1 点直伤 | 1.5 |
| 全场加成 +1/+1 | 3 |
| 消灭目标 | 5 |
| 放逐目标 | 5 |
| 从回响区回收一张生物 | 4 |

## 苛求的分层纪律

`苛求〈2 张色〉` 返还约 2 点价值，`苛求〈3 张色〉` 返还约 4 点。

- **不使用 `苛求〈1 张色〉`**。概率测算显示即使在五色牌组中支付率仍约 90%，
  它不构成有效门槛，只是一行无意义的文字。
- LV0 ~ LV1：不带苛求。这一层是燃料，必须无条件可用。
- LV2：可带 `苛求〈2 张色〉`，同层内应保留不带苛求的牌以形成混合。
- LV3：多数带 `苛求〈2 张色〉`。
- LV4：全部带 `苛求〈2 ~ 3 张色〉`。

苛求可扩展至颜色之外的牌张属性，例如 `苛求〈3 张武装〉`、`苛求〈1 张生物〉`。
牌型类苛求的门槛远紧于颜色类，返还价值相应提高。

## 通用纪律

1. **拒绝白板。** 每张牌都必须有第二重价值——余响、被支付为代价时的效果、
   或条件触发。抽到即卡手的牌不应存在。
2. **余响不得直击指挥官。** 余响只能影响场上实体或提供通用收益。
   例外：践踏溢出属于战斗结算的自然结果，不受此条限制。
3. **复活类效果统一附带「它的登场效果不触发」。** 这是全游戏防循环的标准模板。
4. **针对特定牌型的解答必须有兜底模式。** 本游戏暂无副牌，
   任何只能解武装或只能解地形的牌都必须在没有目标时改为别的用途。
5. **指挥官生命 25。**
