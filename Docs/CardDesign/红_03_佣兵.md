# 红色 · 佣兵系 · R-021 ~ R-030

**状态：已定稿（劫掠的抽空规则待裁定）。**

## 体系论点

佣兵的核心是**互相支援**：每一张佣兵都低于白板基准，但各自给队伍一种不同的东西。
**用数量换质量，靠搭配应对各种局面。**

## 两条数值纪律

**光环计价**：按"场上平均 2 个其他佣兵"计价，真空中价值为 0。
因此佣兵的本体数值一律低于白板基准——这是"用数量换质量"在数字上的落实。

**劫掠的定义**：

```
劫掠〈N〉：将对手牌组顶的 N 张牌置入其墓地。
```

磨进墓地的牌**永远不会变成对手的回响区燃料**。在一个以回响区为资源引擎的
游戏里，劫掠不只是砍牌组厚度，它是从源头掐掉对手后半局的代价供给。
纯破坏，己方不获得任何资源。

代码侧 `ELocation` 已有 `Grave` 与 `Banish`，墓地是现成区域；回响区待补。

## 待裁定：牌组抽空规则

劫掠挂在 R-022、R-028、R-029、R-030 四张上，作为次要轴。强度取决于：

- **抽空即输**：佣兵拿到第二条胜利路线，现有数值按此平衡
- **抽空不输，抽不到就跳过**：劫掠退化为纯资源封锁，需上调数量
- **抽空时指挥官受递增伤害**：折中，劫掠变成慢性斩杀
